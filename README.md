# seismic_art gallery

**Seismic amplitude as data art, from a model and from Volve.**

Seven D3 sketches turn seismic amplitude into pictures: rings, cities, growth rings,
flow fields, trace shells, fault constellations and one thread. GitHub Pages serves them
from this repo.

## What is shown
Most figures are synthetic: generated by the `seismic_art` project from a convolutional
model, with no real survey. The Volve page shows the same sketches on small extracts of
the real Volve dataset, with the cities replaced by the interpreted surfaces, named from
the interpreters' own files, and the fault constellations checked against the
interpreters' fault polygons. Amplitudes are relative, and every figure states its domain
and polarity.

## How this repo is made
It is a published copy of the `web/` folder of the private `seismic_art` project, written
by that project's `scripts/publish_gallery.py`. Edit the project, not this copy.

`vendor/d3.min.js` is D3 7.9.0 (ISC licence, `vendor/D3-LICENSE.txt`).
